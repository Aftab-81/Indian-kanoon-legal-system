# Evaluation Pipeline — Judicial Insight Engine

> Automated [Ragas](https://docs.ragas.io/) quality metrics for the four core AI modules of the Legal Case Analysis System.

---

## Overview

| Module | Port | What is evaluated |
|---|---|---|
| **Legal QA** | 8002 | Answer faithfulness, relevancy, context precision/recall, factual correctness |
| **Research** | 8001 | Context precision, recall, entity recall for hybrid FAISS search |
| **Summary** | 8003 | Summary faithfulness and coverage completeness |
| **Comprehension** | 8000 | Per-field extraction accuracy and semantic similarity |

Evaluation results are exposed by a **FastAPI service on port 8005** and visualised in the **React dashboard at `/evaluation`**.

## Quick Start

### 1. Prerequisites

All backends started and `.env` files contain a valid `OPENAI_API_KEY`.

```bat
REM Start everything (including evaluation API on 8005)
start_all.bat
```

Or start only the evaluation service:

```bat
start_eval.bat
```

### 2. Instant Demo (no API calls, no backends)

Seed realistic demo results to see the dashboard immediately:

```bat
venv\Scripts\python.exe evaluation\scripts\seed_demo_results.py
```

Then open **http://localhost:5173/evaluation**.

### 3. Real Evaluation

Run both steps in order (or trigger them from the dashboard):

```bat
REM Step 1: build datasets (calls live backends + OpenAI for references)
venv\Scripts\python.exe evaluation\build_datasets.py --module all

REM Step 2: run Ragas metrics (calls OpenAI for judging)
venv\Scripts\python.exe evaluation\run_eval.py --module all
```

Per-module:

```bat
venv\Scripts\python.exe evaluation\build_datasets.py --module legal_qa
venv\Scripts\python.exe evaluation\run_eval.py       --module legal_qa
```

## Metrics by Module

### Legal QA (8002)

| Metric | Description |
|---|---|
| `faithfulness` | Answer is grounded in retrieved chunks |
| `response_relevancy` | Answer is relevant to the question |
| `llm_context_precision_with_reference` | Relevant chunks ranked highly |
| `context_recall` | Reference answer covered by retrieved chunks |
| `factual_correctness` | Factual accuracy vs. reference |
| `cites_page_numbers` *(AspectCritic)* | Response cites page numbers from source |

### Research (8001)

| Metric | Description |
|---|---|
| `llm_context_precision_with_reference` | Relevant results ranked at top |
| `context_recall` | Reference information covered by search results |
| `context_entity_recall` | Named entities in reference appear in context |

### Summary (8003)

| Metric | Description |
|---|---|
| `faithfulness` | Summary grounded in source (SummarizationScore substitute¹) |
| `response_relevancy` | Summary relevant to the case |
| `covers_core_elements` *(AspectCritic)* | Facts + legal issue + decision present |
| `no_invented_details` *(AspectCritic)* | No hallucinated parties/sections/dates |

> ¹ `SummarizationScore` is not available in Ragas 0.2.15. `Faithfulness + ResponseRelevancy` is used instead.

### Comprehension (8000)

| Metric | Description |
|---|---|
| `faithfulness` | Extracted field grounded in source |
| `factual_correctness` | Factual accuracy of extraction vs. reference |
| `semantic_similarity` | Embedding cosine similarity to reference |
| `field_is_complete` *(AspectCritic)* | Field fully captured without omissions |

Per-field breakdown is displayed in a dedicated bar chart.

## Configuration

Edit `evaluation/config.py` to control:

| Setting | Default | Effect |
|---|---|---|
| `SAMPLE_LIMIT` | `20` | Max samples per module |
| `JUDGE_MODEL` | `gpt-4o-mini` | OpenAI model for judging |
| `EMBED_MODEL` | `text-embedding-3-small` | Embedding model |
| `MAX_WORKERS` | `4` | Parallel HTTP/LLM calls |
| `SAMPLE_PDFS` | 10 judgments | Corpus for QA/Summary/Comprehension |

## Result File Format

`evaluation/results/<module>.json`:

```json
{
  "module": "legal_qa",
  "metadata": {
    "reference_type": "auto_generated",
    "ragas_version": "0.2.15",
    "judge_model": "gpt-4o-mini",
    "run_timestamp": "2026-10-01T10:16:40Z",
    "n_samples": 18,
    "metrics_used": ["faithfulness", "response_relevancy", ...]
  },
  "aggregate": {
    "faithfulness": 0.8123,
    "response_relevancy": 0.7654,
    ...
  },
  "samples": [
    {
      "id": "abc12345",
      "user_input": "What was the main legal issue?",
      "response": "The court held that...",
      "retrieved_contexts": ["...chunk 1...", "...chunk 2..."],
      "reference": "The main issue was...",
      "scores": { "faithfulness": 0.87, ... },
      "flag": "ok"
    }
  ],
  "notes": ["..."]
}
```

`flag` is `"low"` when the sample's mean score < 0.60 (configurable via `LOW_SCORE_THRESHOLD` in `run_eval.py`).

## Known Decisions & Constraints

| Decision | Reason |
|---|---|
| Ragas 0.2.15 pinned | Stable `EvaluationDataset` + `SingleTurnSample` API |
| `langchain_community.chat_models.vertexai` stub patched | `langchain-community>=0.3` dropped it; stub prevents import crash |
| `SummarizationScore` substituted | Not available in Ragas 0.2.x; `Faithfulness + ResponseRelevancy` used instead |
| `gpt-4o-mini` as judge | Same model as Legal QA backend — consistent and cost-effective |
| Evaluation runs in batch, not user request path | Avoids latency impact on production backends |
| Reference answers auto-generated by LLM | No human-annotated ground truth exists; treat scores as indicative |
| Port 8005 for eval API | No conflict with existing services (8000–8004) |

## Troubleshooting

**Dashboard shows "Evaluation API offline"**
```bat
start_eval.bat
REM or:
venv\Scripts\python.exe -m uvicorn evaluation.api:app --port 8005
```

**`ModuleNotFoundError: langchain_community.chat_models.vertexai`**
The patch in `venv/Lib/site-packages/ragas/llms/base.py` may have been overwritten by a pip upgrade. Re-apply:
```python
# lines 8-9 of ragas/llms/base.py — wrap with try/except:
try:
    from langchain_community.chat_models.vertexai import ChatVertexAI
except (ImportError, ModuleNotFoundError):
    class ChatVertexAI: pass
try:
    from langchain_community.llms import VertexAI
except (ImportError, ModuleNotFoundError):
    class VertexAI: pass
```

**Build datasets fails with "backend not reachable"**
Start all backends first (`start_all.bat`), then run `build_datasets.py`.

**Recharts not found**
```bat
node -e "require('child_process').execSync('npm install recharts --save',{cwd:'front-end',stdio:'inherit'})"
```

## Cost Estimate

Per full evaluation run (all 4 modules, 20 samples each, `gpt-4o-mini`):

| Step | Est. tokens | Est. cost |
|---|---|---|
| Dataset generation (references) | ~120k input, ~40k output | ~$0.04 |
| Ragas evaluation (judging) | ~200k input, ~30k output | ~$0.05 |
| **Total** | | **< $0.10 per run** |

Use `SAMPLE_LIMIT=5` for dev/testing to reduce cost further.
